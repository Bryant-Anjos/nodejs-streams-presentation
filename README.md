# Node.js Streams — Presentation

Slide deck about **Node.js Streams** presented at **Field Hack**. Covers stream fundamentals, memory and time efficiency, readable/writable/transform streams, and pipeline composition.

Built with [Marp](https://marp.app/), which converts Markdown into presentation slides.

## Topics

- What are streams and why use them
- Memory efficiency vs. buffering
- Buffer and Chunk concepts
- Readable, Writable, and Transform streams
- `pipe` and pipeline composition

## Viewing the slides

```bash
npm install
npm run start   # preview with live reload
npm run build   # export to dist/
```

Or open `PITCHME.html` directly in the browser for a static version.
